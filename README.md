

# COVID-19 Image Classification

## Overview
This project uses Deep Learning and Convolutional Neural Networks (CNNs) to classify chest X-ray images into two categories: **COVID-19** and **Normal**. The model is developed using TensorFlow and Keras to assist in the early detection of COVID-19 from medical images.

## Features
- COVID-19 vs Normal chest X-ray classification
- Image preprocessing and normalization
- CNN model built using TensorFlow/Keras
- Model training and evaluation
- Performance visualization with accuracy and loss graphs
- Prediction on new chest X-ray images

## Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- Pandas
- Matplotlib
- Seaborn
- OpenCV
- Jupyter Notebook

## Dataset
The dataset contains chest X-ray images classified into two categories:
- COVID-19
- Normal

## Project Workflow
1. Import required libraries
2. Load and preprocess the dataset
3. Build the CNN model
4. Train the model
5. Evaluate model performance
6. Predict COVID-19 from new X-ray images

## Objective
To develop an AI-based diagnostic system capable of detecting COVID-19 from chest X-ray images with high accuracy, helping support faster medical diagnosis.
